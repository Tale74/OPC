## Invariant allocation

- PREDMET owns lifecycle, identity and applied snapshot persistence.
- SCENARIO can calculate or propose; only the PREDMET application contract applies a snapshot.
- IRiU owns order and row composition, never the master record.
- KATALOG owns reusable catalog values, never historical PREDMET snapshots.
- Persistence owns storage mechanics, never the meaning of stored business truth.
- Interoperability workflows own coordination; infrastructure owns codecs, filesystem and persistence adapters.
- PREDMET owns reminder source facts; PODSETNIK may own only derived scheduling/delivery/confirmation state.
- Derivatives (PARTE, documents, reminders, stock, statistics) consume authoritative snapshots and cannot silently become authorities.
