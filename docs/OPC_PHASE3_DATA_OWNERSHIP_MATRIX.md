# OPC Phase 3 Target Data Ownership Matrix

| Entity/state | Master owner | Readers | Writers | Derived/snapshot rule | Persistence / transfer | Compatibility obligation |
|---|---|---|---|---|---|---|
| PREDMET identity and lifecycle | PREDMET core | All derivatives through contract | PREDMET lifecycle application | No parallel feature copy is authoritative | `predmeti` records; versioned JSON/backup | Existing lifecycle, identity, hard-delete and upgrade behavior |
| IRiU rows | PREDMET-scoped IRiU application boundary | UI, stock, finance, documents | IRiU workflow under PREDMET command | Ordered rows are `OSNOVNI → applied SCENARIO → manual/unpredicted` | `iriu` tables and transfer envelope | Ordering, provenance, quantity/price and manual-row tests |
| KATALOG articles/categories/labels | KATALOG | Picker, IRiU, seed/configuration | Catalog application/data ports | Read values may be snapshotted into PREDMET; no retroactive rewrite | Catalog tables and catalog transfer data | Seed idempotency, current-price and picker contracts |
| SCENARIO definitions/rules | SCENARIO module | Scenario editor/runtime, PREDMET application | Locked scenario contracts | Definition changes are not retroactive to applied snapshot | Scenario tables and transfer envelope | Locked source SHA and Tier 1/2/3 regression contract |
| Applied SCENARIO snapshot/provenance | PREDMET | IRiU, documents, audit, transfer | PREDMET application contract | Immutable per applied PREDMET version; provenance retained | Snapshot/provenance tables and single-PREDMET JSON | Non-retroactivity, carrier and reconciliation contracts |
| PARTE preparation state | PARTE workflow | PARTE UI/export | PARTE application/repository | Derived from PREDMET and templates | PARTE tables/media and export metadata | Schema 2.0, print and JSON tests |
| Reminder source lifecycle/business facts | PREDMET core | PODSETNIK, UI and workflows | PREDMET lifecycle application only | PODSETNIK reads facts; it cannot duplicate or rewrite them | `predmeti` records; not independently transferred as reminder truth | Existing lifecycle/identity/upgrade obligations |
| Derived reminder scheduling/delivery/confirmation state | PODSETNIK (derived-state owner only) | Reminder UI and platform gateway | Reminder scheduler/confirmation workflow | Derived state references PREDMET facts; signal taxonomy/business meaning remains owner-gated | Reminder state tables/notifications and backup metadata | Current observable behavior plus future owner decision |
| Stock availability/effects/consequences | STANJE ROBE | Stock UI, operational workflows | Effects/reconciliation application | Operational projection over PREDMET/IRiU | Stock/effect/consequence tables and backup | Delete/restore, stock and JSON boundary tests |
| Users/session/FIRMA/settings | Identity/settings | App composition and feature workflows | Identity/settings application | Context/configuration, not business truth | User, firm, settings tables and backup | Recovery, identity and app-context behavior |
| Transfer/backup metadata | Interoperability workflow | Restore UI, diagnostics, support | Transfer/backup coordinator | Describes payload/version/restore intent, not PREDMET meaning | Versioned envelopes/filesystem metadata; technical adapters are infrastructure | Old format readers, validation and rollback obligations |
| Generated persistence access | Persistence build output | Repositories/migrations | Drift generator | Never hand-edited or treated as domain authority | `database.g.dart` and generated schema | Generator/version compatibility |
