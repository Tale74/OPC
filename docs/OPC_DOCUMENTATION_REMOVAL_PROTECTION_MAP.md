### B-01 — owner-decision-bearing task report bez direktnog current registra

Report sadrži owner-decision/acceptance signal, ali njegov filename ili task identitet nije direktno pronađen u current owner decision corpus-u. Pre brisanja mora se izvršiti semantička ekstrakcija odluke ili dokazati da je odluka supersedovana.

### B-02 — lokalni master/mixed-history dokument

Veliki lokalni dokument sadrži current owner pravila pomešana sa istorijom. Postojeći javni summary nije dovoljan dokaz potpune zaštite bez section-by-section cross-map-a.

### B-03 — lokalni untracked root dokument

Fajl nema Git lineage i može sadržati jedinstvenu odluku/dokaz. Potrebna je sadržinska ekstrakcija ili dokazani superseding dokument pre brisanja.

### B-04 — dodatna current-tree privacy izloženost

Pored odobrene sanitizacije manifesta, još dva zadržana current authority dokumenta sadrže privatnu apsolutnu lokalnu putanju. Njihova sanitizacija nije bila obuhvaćena uskom owner formulacijom i zahteva potvrdu ili proširenje autorizacije.
