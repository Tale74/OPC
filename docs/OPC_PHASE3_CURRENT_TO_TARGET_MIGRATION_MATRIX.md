## Rewrite decision rule

Partial or full reconstruction is preferable to progressive refactor only when responsibilities are inseparably mixed, the stable contract is characterized, a bounded replacement can sit behind a port, and compatibility/recovery rehearsal is available. It is not justified for cosmetic naming, a coherent block, or when tests and data contracts are insufficient. Every migration step must preserve a reversible adapter or prove an equivalent compatibility path.
